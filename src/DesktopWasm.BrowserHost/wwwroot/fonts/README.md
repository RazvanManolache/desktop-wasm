# Shared application fonts

Unmodified Noto Sans Regular and Noto Sans Mono Regular from
[notofonts/noto-fonts](https://github.com/notofonts/noto-fonts/tree/ffebf8c1ee449e544955a7e813c54f9b73848eac),
commit `ffebf8c1ee449e544955a7e813c54f9b73848eac`, under `hinted/ttf/`.
Copyright and SIL Open Font License 1.1 are included in `OFL.txt`.
The font files are shared by browser Canvas2D drawing, Skia GPU drawing and
the layout text shaper, so changing renderer does not select a different font.
